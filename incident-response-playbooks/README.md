#  Incident Response Playbooks

This project contains structured Incident Response (IR) Playbooks designed to help organizations effectively detect, contain, and recover from cybersecurity incidents.

##  Overview

Developed as part of a cybersecurity capstone project, these playbooks simulate real-world incident handling aligned with industry standards.

##  Covered Incidents

* Phishing Attacks
* Ransomware Infections
* Distributed Denial of Service (DDoS) Attacks

##  Framework

Based on the NIST SP 800-61 Incident Response Lifecycle:

* Detection & Analysis
* Containment
* Eradication
* Recovery

##  Key Features

* Time-based response phases (MTTD / MTTR focused)
* RACI-aligned roles and responsibilities
* Communication matrices for stakeholders
* Ransom decision framework
* Post-incident review template
* Quick-response checklists
